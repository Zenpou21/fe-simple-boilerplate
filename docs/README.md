# Learn the tools

One short guide per tool. Each one says **what it is**, **where this kit uses it**, and **how to use it**, with examples taken from the kit's own code.

Read them in this order if the stack is new to you:

| # | Guide | In one line |
| --- | --- | --- |
| 1 | [TypeScript](01-typescript.md) | JavaScript with types, so mistakes show up in the editor |
| 2 | [React](02-react.md) | building the screen out of components |
| 3 | [Vite](03-vite.md) | the dev server, `.env` and the build |
| 4 | [Tailwind CSS](04-tailwind.md) | styling with class names |
| 5 | [HeroUI](05-heroui.md) | ready-made buttons, tables, drawers, inputs |
| 6 | [React Router](06-react-router.md) | pages and URLs |
| 7 | [SWR](07-swr.md) | loading and caching data from the API |
| 8 | [react-hook-form + zod](08-forms-and-zod.md) | forms and their validation |
| 9 | [lucide-react](09-icons.md) | icons |
| 10 | [npm, ESLint and handy tools](10-npm-and-tools.md) | installing packages, checking code, debugging |

The project's own code (how `useCrud`, `useServerTable` and the Products example fit together) is explained in the main [README](../README.md).
